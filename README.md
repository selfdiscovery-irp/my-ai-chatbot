# My AI Chatbot

A simple AI chatbot web application built with HTML, CSS, and JavaScript.

## Features

- Clean and simple chatbot interface
- User message input
- Send button
- Press Enter to send messages
- Responsive design for mobile and desktop
- Hosted using GitHub Pages

## Project Status

This is the first version of the chatbot.

The current version has a basic chat interface. AI API integration will be added in a later step.

## Technologies Used

- HTML
- CSS
- JavaScript
- GitHub Pages
